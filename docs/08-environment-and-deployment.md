# 환경 준비·DB 운영·배포

시작 가정: GitHub repo·인증·Vercel 등 설정 완료. goal 전에 18번 전용 점검으로 실제 가능 여부를 확인한다. 앱 외부 연결은 아직 미검증이다. 문서 저장소의 Git 연결 상태는 PROGRESS에서 확인한다. 실제 접근 실패는 환경 차단이다.

## 필요한 연결

| 항목 | 선행조건 | 에이전트가 수행할 일 |
|---|---|---|
| Codex | goal·서브 에이전트·파일·터미널·브라우저 환경 | 개발·검토·테스트·인계 |
| GitHub | 지정 repo·remote·인증·push/PR/merge·Actions 권한 | 체크포인트·CI·통합 |
| Vercel | CLI/도구 인증, 프로젝트 생성·배포·환경변수 권한 | 프로젝트 연결·배포·로그 확인 |
| Neon/PostgreSQL | 허용된 DB 프로젝트·격리 자원 생성 권한, 필요한 계정/약관 준비 | DB/격리 스키마 또는 branch 준비·마이그레이션·seed |
| AI Gateway | 접근 가능한 모델·크레딧·서버 인증 | 실제 호출·품질·오류·사용량 검증 |
| Gemini API | 사용자가 발급·주입한 서버 키, 확인된 무료 프로젝트·모델 한도 | 직접 호출 어댑터·품질·전환 후 E2E·사용량 검증 |
| 개발 런타임 | Node.js·패키지 관리자·테스트 브라우저 설치 가능 | 버전 선택·설치·lockfile |
| 네트워크 | 패키지·DB·모델·배포 연결 가능 | 필요한 연결만 사용 |

로그인·이메일 인증·2단계 인증·최초 약관·관리자 제한이 나타나면 사용자 참여가 필요할 수 있다. 자격증명을 대화나 문서에 붙여넣도록 유도하지 않는다. 유료 전환·크레딧 구매·자동 충전은 별도 명시적 동의 없이 실행하지 않는다.

## Codex/GPT Workspace와 API

- 제공되는 Workspace는 코드 생성·개발 권한이다. 배포 앱의 일반 LLM API 무료 권한이 자동으로 포함된다고 가정하지 않는다.
- OpenAI Platform API는 별도 접근·과금이 기본이며, Enterprise 계약의 별도 제공 여부는 주최 측 확인 대상이다.
- Codex access token은 허용된 Codex 자동화용이다. 일반 모델 API 키로 사용하지 않는다.
- Workspace Agents API는 당시 공식 문서상 실행/상태 조회와 응답 본문 조회가 다르다. 원하GS 실시간 검색의 기본 경로로 삼지 않는다.
- ChatGPT 로그인 토큰을 공개 웹앱의 범용 추론 프록시로 옮기는 방식을 기본안으로 사용하지 않는다.

## Vercel AI Gateway

기준선은 Vercel 계정의 Gateway를 서버에서 호출하는 것이다. 배포 환경은 OIDC, 로컬은 지원되는 Gateway 인증 방식으로 검증한다.

조사 당시 무료 등급은 월 $5 크레딧·일부 모델·모델별 호출 제한이 안내됐다. 전 모델 무료·무제한·특정 임베딩 모델 사용 가능이라고 보장하지 않는다. 실제 계정 잔여량과 모델 목록을 확인한다. 플랫폼 실행·DB·LLM 각각 무료 한도가 따로 있다는 점을 기록한다.

주최 측 확인 문구:

> 제공 Workspace 외 앱 실행용 API 프로젝트/크레딧이 있나요? 없다면 Vercel AI Gateway 무료 크레딧 사용이 허용되나요? 런타임 모델에 제한이 있나요?

## 본 구현 전 환경 검사

1. 지정 경로에서 프로젝트 작업이 가능한지 확인한다.
2. Vercel 인증과 대상 팀·플랜을 확인한다.
3. 최소 페이지·서버 API를 Preview로 배포한다.
4. 허용된 격리 Neon/PostgreSQL 리소스를 연결하고 테스트 레코드 write/read를 검증한다.
5. 배포 서버에서 실제 LLM을 호출하고 한국어 응답을 받는다.
6. 브라우저 입력 → 서버 → DB → 화면 결과를 검증한다.
7. 테스트 실행·데모 초기화·로그 확인을 검증한다.
8. 임베딩을 선택할 경우 실제 임베딩 모델과 pgvector 쿼리를 별도 검증한다.

기록: 대상 팀·환경, 비밀값을 제외한 버전/리소스 식별자, 검증 시각, 명령/결과, URL, 실패 사유, 모델·사용량. 로그인 화면만 확인한 것을 실제 호출 성공으로 보고하지 않는다.

## DB 관리

- 마이그레이션 파일과 seed를 저장소에 포함한다.
- 개발/테스트와 제출용 DB 또는 브랜치를 분리한다. Preview가 제출 데이터를 초기화하지 않도록 연결 범위를 확인한다.
- 빌드나 함수 시작 때마다 마이그레이션·seed를 자동 실행하지 않는다. 통제된 배포 단계로 실행한다.
- 서버리스에 맞는 pooled connection/드라이버를 사용하고 짧은 트랜잭션을 유지한다.
- 거래 상태는 DB를 기준으로 판단한다. 서버 로컬 파일·메모리·localStorage를 공용 DB로 사용하지 않는다.
- 무료 플랜의 중지·연산·저장·복구 한도를 실제 계정에서 확인한다. 백업이 자동 제공된다고 가정하지 않는다.
- 제출 직전 데이터 내보내기와 seed 기반 복구 경로를 확인한다.
- DB 삭제나 전체 초기화 대신 데모 세션 범위의 reset을 제공한다.

## 배포 절차

1. 타입 검사·단위·통합·빌드를 수행한다.
2. Preview 환경의 DB·Gateway 인증과 Gemini 서버 키·모델 설정을 준비한다.
3. Preview 배포 후 브라우저 E2E와 실제 모델 연결을 확인한다.
4. 승인된 범위에서 제출용 Production 배포를 수행한다.
5. 심사자가 접근 가능한 URL인지, 개발자 로그인 없이 허용된 데모를 사용할 수 있는지 확인한다.
6. Production의 DB 분리·실제 LLM 모드·데모 초기화·48시간 경계를 재확인한다.
7. URL, 버전, 증거, 제한을 보고한다. Preview 성공만으로 최종 배포 성공이라고 하지 않는다.

이번 경로는 GitHub·Actions·PR 기반이다. Vercel CLI는 기본 동작 검사·진단·복구에 사용 가능하나 16번 Git 이력과 검증을 건너뛰지 않는다. 실제 명령·옵션은 설치된 CLI 도움말을 확인한다. 예시 `vercel integration add neon`은 실행 안내이지 이미 실행했다는 뜻이 아니다.

## 시간·재검토·알림

Vercel Hobby Cron의 조사 당시 제한은 하루 한 번·시간 단위 정확도다. 정확한 48시간 수령 제한은 DB deadline 비교로 보장한다. 마감 순간 앱이 닫혀 있어도 알림이 발송된다는 약속은 하지 않는다. 미확보 재검토는 이벤트·버튼으로 실행하고 장기 상주 프로세스를 가정하지 않는다.

## 최종 인계 항목

코드·lockfile, 마이그레이션·seed, 환경변수 이름만 적힌 예시 파일, 실행/테스트/초기화 안내, 배포 URL, 검증 결과, 모델/데이터 버전, 알려진 제한, 유료 전환 여부. 비밀값과 실제 고객 정보는 포함하지 않는다.

## 검증 준비 추가

M0에서는 테스트 실행기·서브 에이전트/스킬 가용성을 확인하고 GATE-BOOTSTRAP을 준비한다. 실제 DB 드라이버에서 필요한 트랜잭션·잠금·동시 갱신도 최소 검증한다. CRUD 연결과 DB 업무 적합성을 구분한다.

환경별 DB 식별자와 배포 revision/schema를 확인한 뒤 destructive 테스트를 격리한다. 초기 환경 기본 동작 검사 배포는 제품 릴리스와 다른 게이트다. 제출 배포는 [14번](14-agent-development-loop.md)의 G5 선행조건과 G6 실제 URL 검증을 요구한다. 앱 버전 복구가 DB 스키마 복구까지 포함한다고 가정하지 않는다. 현재 실행기/CI는 미구현이다.

## 사전 설정 완료의 의미

지정 repo의 push/PR/merge·Actions, 연결된 Vercel Preview/Production, 격리 DB와 실제 앱 모델에 접근 가능한 인증이 있어야 한다. CI 모델 인증이 없으면 허용된 로컬 목표 환경에서 정확한 Preview를 검사하고 증거를 연결할 수 있다. 계정/크레딧 자체가 없는 것은 설계로 해결되지 않는다.

인간 승인 필수·조직 보호 규칙은 사전 허용 경로가 준비돼야 한다. 실행 중 보호 해제나 가짜 approval로 우회하지 않는다. 일상 개발/정책마다 재승인은 요구하지 않는다. [18번 사전점검](18-environment-preflight.md)에 사용법과 실제 시험 범위를 정리한다.

## 2026-09-20 재확인

[Gateway 가격](https://vercel.com/docs/ai-gateway/pricing)은 월 $5 무료 크레딧·일부 모델·낮은 모델별 rate limit을 여전히 안내한다. 외부 검토의 ‘$5가 사라졌다’는 취지로 고치지 않는다. 유료 credit 구매 시 무료 조건이 달라지므로 구매/자동 충전 없이 실제 잔량과 충분한 eval 호출 계획을 확인한다. 카드 요구 여부는 해당 계정에서 확인한다.

[Gateway 인증](https://vercel.com/docs/ai-gateway/authentication-and-byok)은 API key와 Vercel 배포 OIDC를 지원한다. 로컬/CI/배포별 경로를 따로 검증하고, API key를 모든 환경에 중복 설정하는 것을 필수로 만들지 않는다. 대체 provider는 실제 무료 접근·키·한도와 한국어 품질 검증 후 선택하며 이 문서가 계정 가입/유료 구매를 대신하지 않는다.

## Gemini 예비 경로

D-31에 따라 Gemini API 직접 호출을 함께 준비한다. 키는 사용자가 발급해 필요한 로컬/CI/Preview/Production 비밀 저장소에 주입한다. 테스트 묶음 전후와 배포 직전에 양쪽 한도를 확인하고, Gateway 잔량이 필수 검증·데모 예산보다 적으면 검증한 Gemini 모델로 전환한다. 같은 계정의 무료/유료 등급을 확인하며 저가라는 이유로 유료 호출을 허용하지 않는다. 상세 절차와 공식 출처는 [25번](25-model-budget-and-fallback.md)에 있다.

## Neon 계정 이후 준비

2026-09-21 사용자가 Neon 계정 생성 완료와 프로젝트 `green-unit-60810095`·`production` 브랜치 안내를 제공했다. 실제 프로젝트 접근·브랜치 ID·DB URL·플랜·격리는 미검증이다. [28번 연결 가이드](28-neon-setup-guide.md)에서 받은 일곱 단계를 현재 구조에 맞게 구분했다.
