# 모델 사용량과 Gemini 전환

상태: 2026-09-21 설계 추가. D-31·CORE-23·AC-29에 따른 구현 요구다. 실제 계정 잔량, Gemini 키, 모델 호출은 아직 확인하지 않았다.

## 기본 경로와 예비 경로

Vercel AI Gateway를 기본으로 사용한다. 테스트 중과 배포 직전에 잔량을 확인하고, 남은 필수 검증과 데모를 감당하기 어려우면 미리 검증한 Gemini API 직접 호출로 전환한다. Gemini 키는 사용자가 발급해 서버 환경변수에 주입한다.

앱 서버에 두 제공자를 같은 입출력 계약으로 연결한다. 상품 후보·확인 질문·경영주 명령 해석을 검증하는 서버 코드는 공유한다. 제공자 선택은 서버 설정으로 제한하고 고객 입력으로 모델이나 API 주소를 바꾸게 하지 않는다.

| 설정 초안 | 용도 |
|---|---|
| `LLM_PROVIDER=gateway` 또는 `gemini` | 해당 배포에서 사용할 경로 |
| `GATEWAY_MODEL_ID` | Gateway에서 검증한 모델 ID |
| `GEMINI_MODEL_ID` | Gemini 직접 호출에서 검증한 모델 ID |
| `GEMINI_API_KEY` | 사용자가 주입하는 서버 비밀값. SDK가 다른 이름을 요구하면 서버 어댑터에서 명시적으로 연결 |
| `LLM_MODE=live` 또는 `fixture` | 실제 호출과 고정 테스트 응답 구분 |

Gemini 경로는 Google API로 직접 연결한다. Gateway 내부의 모델 변경이나 Gemini 키를 Gateway에 등록하는 BYOK만으로 예비 경로를 대신하지 않는다. Gateway 무료 크레딧과 Google 프로젝트의 무료 호출 한도는 따로 확인한다. [Gateway 가격·BYOK 조건](https://vercel.com/docs/ai-gateway/pricing)

## 모델 후보 확인

사용자가 예로 든 `gemini-3-flash-lite-preview`는 설정값으로 확정하지 않는다. 확인한 공식 문서는 `gemini-3.1-flash-lite-preview`가 2026-05-25 종료됐다고 안내한다. 새 실행에서는 사용 가능한 정식 모델을 조회한다. [Preview 종료 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite-preview)

2026-09-21 확인한 요금표에서 다음 텍스트 모델은 무료 등급을 제공한다. 표의 유료 단가는 비교 참고이며 유료 사용 승인이나 현재 계정의 무료 접근을 뜻하지 않는다. [Gemini 요금표](https://ai.google.dev/gemini-api/docs/pricing)

| 후보 | 유료 입력 / 출력, 각각 100만 토큰당 USD | 선택 기준 |
|---|---|---|
| `gemini-2.5-flash-lite` | $0.10 / $0.40 | 저가 후보로 먼저 평가 |
| `gemini-3.1-flash-lite` | $0.25 / $1.50 | 한국어·구조화 출력 품질을 비교할 후보 |

goal 실행 시 모델 제공 여부·무료 등급·실제 계정 한도를 다시 확인한다. 접근 가능한 후보 중 출시 최소 품질과 데모 응답 시간을 만족하는 저가 모델을 선택하고 모델 ID를 고정한다. 응답 형식, 도구 호출, 토큰 집계 차이는 어댑터에서 처리한다.

무료 Gemini 사용 조건에는 입력·출력의 제품 개선 활용이 포함될 수 있으므로 모의 상품 요청과 합성 사용자 데이터로 검증한다. API 키나 기업 비공개 자료를 프롬프트에 넣지 않는다. [Gemini 요금·데이터 이용 구분](https://ai.google.dev/gemini-api/docs/pricing)

## 잔량 확인과 예산

사전점검 P01/P08, 각 실제 모델 평가 묶음의 전후, G5 시작 전, Production 배포 직전, G6 완료 후에 확인한다. 이전 단계의 기록을 재사용할 때는 확인 시각과 이후 사용량을 함께 제시한다.

- Gateway: 공식 잔액 조회 API 또는 인증된 대시보드에서 대상 팀의 잔액·확인 시각을 읽는다. `GET /v1/credits`와 개별 요청 사용량 조회의 인증·응답 형식은 구현 당시 문서와 실제 응답으로 확인한다. [Gateway 사용량 API](https://vercel.com/docs/ai-gateway/observability-and-spend/usage)
- Gemini: 프로젝트의 무료/유료 등급, 모델별 RPM·TPM·RPD와 재설정 시각을 확인한다. 제한은 API 키별이 아닌 프로젝트별이다. 키를 더 발급해 한도를 늘리는 방식은 사용하지 않는다. [Gemini 호출 제한](https://ai.google.dev/gemini-api/docs/rate-limits)
- 공통: 응답에서 받은 입력·출력·추론 토큰, 호출 수, 실패/재시도 수를 기록한다. 다른 앱과 같은 팀·프로젝트를 공유하면 외부 사용량도 고려한다.

잔액 조회가 실패하면 0이나 무제한으로 치환하지 않고 `unknown`으로 기록한다. Gemini의 정확한 남은 호출량을 조회할 수 없다면 확인된 할당량·현재 사용량·로컬 집계의 차이와 불확실성을 남긴다. 키가 있다는 사실만으로 무료 호출을 보장하지 않는다.

필요량은 다음처럼 산출한다.

```text
필수 예비량 = 남은 필수 평가 + 제공자 전환 검증 + G5/G6 + 계획한 데모 횟수
필요 토큰 = 각 흐름의 호출 수 × 측정한 입력/출력 토큰 × 실행 횟수
Gateway 필요 금액 = 토큰별 실제 단가 합계 + 재시도·추론 토큰·오차 여유
Gemini 필요 용량 = 총 호출/토큰 + 동시에 사용할 때의 분당 호출/토큰
```

데모 횟수, 여유 계수, 잔량 기록의 유효시간은 평가 시작 전에 운영 ADR로 정한다. 초기 제안은 예상 사용량의 2배를 확보하는 것이며 사용자가 고정한 수치는 아니다. Gemini는 총량이 남아도 분당 한도로 데모가 지연될 수 있으므로 동시 사용 시나리오도 계산한다.

선택 실험이 필수 예비량을 침범하면 먼저 선택 실험을 멈춘다. 필수 평가의 합격선이나 표본을 결과에 맞춰 낮추지 않는다. 기본 단위·거래 회귀 검사는 고정 응답을 재사용하고 실제 모델 품질·연동 검증에 호출을 집중한다.

## 전환 절차

1. 잔량이 필수 예비량보다 적거나 계획한 데모의 호출 속도를 감당하지 못하면 전환 검토를 시작한다. 잔량을 확인할 수 없고 예비량을 입증하지 못한 경우에도 같은 절차를 적용한다.
2. Gemini 키·무료 등급·한도를 확인하고, 후보 모델로 고객·경영주 구조화 응답과 대표 대화를 실제 호출한다. 동일한 계약·출시 최소 기준으로 검증한 결과가 있어야 한다.
3. 평가 묶음이나 사용자 요청이 끝나는 경계에서 경로를 바꾼다. 서로 다른 제공자의 결과는 구분해 저장한다. 진행 중인 도구 실행·발주·모의 결제를 새 모델에서 재실행하지 않는다. 응답 유실은 기존 실행 ID와 멱등 키의 상태부터 조회한다.
4. Preview 서버 설정을 변경하고 필요한 재배포를 수행한다. 모델·프롬프트·검색·설정 버전을 갱신한 뒤 영향받는 자연어 평가와 고객/경영주 E2E를 다시 실행한다. 기존 모델의 PASS를 새 모델의 증거로 사용하지 않는다.
5. 선택한 제공자 설정으로 G5를 통과한 뒤 Production에 배포한다. 배포 직전 바꿨다면 관련 G5를 다시 확인하고, 실제 제출 URL에서 G6를 수행한다. 환경변수 변경 후 이전 배포가 자동 갱신됐다고 가정하지 않는다.
6. 전환 이유·잔량 근거·모델·검증 결과·배포 ID·설정 버전을 기록한다. 검증한 이전 설정으로의 복구 경로도 남긴다. 복구 대상도 호출 한도가 남아 있어야 한다.

이 전환은 D-31에서 허용한 작업이므로 매번 사용자 판단을 기다리지 않는다. 고객/경영주 화면에 제공자 선택 UI를 추가할 필요는 없다. 제공자별 실행 정보는 서버 로그와 평가 보고서에 남긴다.

실행 중 모든 오류를 자동으로 다른 모델에 재전송하지 않는다. 일시적인 429는 제한된 지연 후 재시도하고, 일일 한도 소진은 해당 경로의 호출을 중단한다. 키 오류·잘못된 JSON·업무 검증 실패는 각각의 오류로 처리한다. 두 경로 모두 사용할 수 없으면 재시도 가능한 실패 상태를 보여주고 원인을 기록한다.

## 비용과 완료 조건

목표는 무료 크레딧과 무료 호출 한도 안에서 테스트와 데모를 마치는 것이다. Google의 유료 프로젝트 키는 무료 이용을 보장하지 않는다. 별도 유료 사용 승인이 없다면 무료 등급이 확인된 프로젝트를 사용하며 자동 충전·크레딧 구매·유료 전환은 하지 않는다. 앱의 사용량 제한은 제공자 과금 차단을 대신하지 않는다.

실제 무료 용량이 부족하면 검증한 Gemini 경로로 전환하거나 한도 재설정 후 재개한다. 두 경로 모두 필수 검증을 감당하지 못하면 외부 차단으로 기록한다. 고정 응답으로 실제 모델 검증을 대체해 완료 처리하지 않는다.

최종 증거에는 두 경로의 연결 시험, 전환 실패 주입 테스트, 최종 선택 모델의 자연어 최소 기준, 고객/경영주 실제 E2E, 제출 URL·설정 버전, 잔량 확인 시각과 남은 데모 계획을 포함한다. 한 번의 잔량 확인으로 이후 무제한 운영을 보장하지 않는다.

Gateway가 이미 소진된 경우에는 실패 원인과 관측 결과를 보존하고 Gemini 성공·전환 검사로 진행한다. 최종 선택 경로와 Gemini 예비 경로의 실제 성공은 필수이며, 사용할 수 없는 Gateway의 과거 성공을 현재 성공으로 표시하지 않는다. Gateway를 다시 선택하려면 당시 연결·품질·한도를 재확인한다.

Neon 계정 안내의 `aiGateway`는 별도 Neon 서비스다. [28번](28-neon-setup-guide.md)에 따라 이번 기준선에서 활성화하지 않으며 D-31의 Vercel AI Gateway/Gemini 예산·전환 계약은 유지한다.
