# [STEP-5] 모집 마감·다음 회차·대기 신청

상태: 요구사항 초안 / 구현 미승인
작성일: 2026-09-21
선행: STEP-4

## 목적

모집이 끝난 뒤에도 새로운 수요를 받을 수 있게 하고, 경영주의 반복 모집 작업을 줄인다.

## 요구사항

- 모집 중·목표 달성·마감 종료 상태를 구분한다.
- 모집 기한이 지나면 신규 신청을 차단하고, 미달 회차는 자동 종료한다. 화면을 열어야만 종료되는 구조를 피한다.
- 종료 사유와 후속 신청 가능 여부를 고객 상태 화면에 전달한다. 경영주가 고객별로 답변하지 않는다.
- 목표 달성 회차의 신규 수요는 기존 발주에 합산하지 않고 다음 회차 또는 대기로 분리한다.
- 다음 회차도 점포·상품별 최소 발주 수량을 목표로 하며 기존 자동/수동 설정을 유지한다.
- 동일 점포·상품에 모집 중인 회차가 중복 생성되지 않도록 한다.
- 이전 신청을 자동 이월하지 않는다. 고객이 다음 모집 대기에 동의한 경우만 연결한다.

## 완료 기준

- 마감 전 미달 요청은 종료 후에도 이력으로 남고 신규 신청은 거절된다.
- 다음 회차 신청이 이전 회차의 수량·발주 결과를 바꾸지 않는다.
- 동시에 신청해도 모집 회차가 중복 생성되지 않는다.
- 대기 미동의 고객은 다음 회차에 임의로 포함되지 않는다.

## 구현 전 결정·데이터

- 다음 회차 생성 시점, 새 모집 기한, 대기 신청 만료·취소 정책을 합의한다.
- 새 회차 자동 발주가 반복될 때 적용할 상한도 결정한다. 무제한 발주는 기본 정책으로 두지 않는다.
- 종료 시각·사유와 대기 동의 보관 방식은 스키마 확정 시 정의한다. 현재 DB에 있다고 간주하지 않는다.
- seed 후보: 미달 마감, 목표 달성 후 신규 요청, 대기 동의/미동의, 동시 다음 회차 생성. SQL은 구현 단계에 작성한다.
- 고객 수령·미수령 처리는 제외한다. 검증은 아직 실행하지 않았다.
