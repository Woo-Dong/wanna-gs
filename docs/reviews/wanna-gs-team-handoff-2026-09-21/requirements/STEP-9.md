# [STEP-9] 요청부터 입고·수령 가능 안내까지 실적 조회

상태: 요구사항 초안 / 구현 미승인
작성일: 2026-09-21
선행: STEP-4 이력, STEP-5 모집 상태, STEP-6 입고·안내 상태

## 목적

경영주가 고객 요청이 모집·발주·입고로 얼마나 이어졌는지 한눈에 확인한다. 고객 픽업을 제외했으므로 실적 범위도 수령 가능 안내까지로 제한한다.

## 요구사항

- 점포별로 조회 기간을 선택하고 요청·모집·발주·입고·수령 가능 안내 실적을 요약한다.
- 사람 수, 상품 수량, 모집 회차 수, 발주 건수를 서로 다른 단위로 표시한다.
- 상품별 유효 요청 수량, 모집 목표 달성 회차 수, 발주 성공·실패 건수, 실제 입고 수량, 수령 가능 안내 수량을 표시한다.
- 발주 실적은 당시 자동/수동 방식으로 구분한다. 현재 설정으로 과거 실적을 다시 분류하지 않는다.
- 요약 항목에서 해당 모집·발주·입고 상세로 이동할 수 있게 한다.
- 수령 가능 안내를 판매·수령 완료로 표현하지 않는다. 근거 없는 매출 증가·업무 절감 수치를 만들지 않는다.
- 데이터 미수집, 조회 오류, 실제 0건을 구분한다. 비율의 분모가 0이면 계산 불가로 표시한다.

## 집계 기준 초안

- 연결 실적은 선택 기간에 생성된 모집 회차를 기준으로 묶고, 그 회차에 연결된 발주·입고의 조회 시점까지 진행을 집계한다.
- 기간 종료 후의 입고가 포함될 수 있음을 표시한다. 특정 날짜의 입고 발생량과 혼동하지 않는다.
- 유효 요청은 취소를 제외한다. 과거 시점 스냅샷이 아니라 조회 시점의 유효 요청임을 명시한다.
- 모집 달성률: 대상 회차 중 목표 달성 회차 비율. 과거 달성 후 상태 변경을 정확히 추적할 데이터 정의는 구현 전에 확정한다.
- 발주 성공률: 발주 결과가 있는 건 중 성공 건 비율. 아직 발주하지 않은 회차는 분모에서 제외한다.

## 완료 기준·데이터

- 요약 수치와 같은 조건의 상세 합계가 일치한다.
- 취소 요청과 중복 입고 이벤트가 실적을 부풀리지 않는다.
- 고객 수령 완료율·미수령률·픽업 완료 수량은 표시하지 않는다.
- 기존 요청·발주 기록과 STEP-6 입고 데이터를 재사용한다. 집계용 테이블 추가 여부는 아직 미정이다.
- seed 후보: 요청만 있음, 발주 실패, 전량/부분 입고, 기간 밖 입고, 실적 없음. SQL·검증은 구현 단계에 진행한다.
- AI 요약 등 이전 제안의 부가 기능은 이번 추출 범위에 포함하지 않는다.
