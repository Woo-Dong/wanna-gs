# [STEP-4] 발주·설정 이력 조회

상태: 기존 구현에서 요구사항 추출
작성일: 2026-09-21
범위: 요구사항 문서만 작성. 기존 구현·검증 기록은 변경하지 않는다.

## 목적

경영주가 추가 입력 없이 과거 요청과 발주 결과, 자동 발주 설정 변경을 확인한다.

## 요구사항

- 고객 요청 현황·상품별 설정과 분리된 이력 화면을 제공한다.
- 점포별 모집 회차를 조회하고 발주 성공·실패·미발주로 필터링한다.
- 회차 상세에 상품, 모집 상태, 목표 수량, 기한, 유효 신청 인원·수량을 표시한다.
- 고객 요청은 닉네임·수량·최초 신청 시각·현재 상태를 표시한다. 취소 요청은 상세에 남기되 집계에서는 제외한다.
- 발주 당시 자동/수동 여부, 수량, 접수 결과, 실패 사유, 참조번호를 표시한다.
- 상품별 설정 변경 전후 값과 기록 시각을 별도로 조회한다. 현재 설정과 과거 발주 방식을 혼동하지 않는다.
- 기록되지 않은 시각이나 사유는 추정하지 않는다. 조회 실패와 빈 목록을 구분한다.

## 완료 기준

- 현재 자동 설정을 꺼도 과거 자동 발주는 자동으로 표시된다.
- 취소 고객을 포함한 상세 목록과 유효 요청 집계가 구분된다.
- 선택 점포 외 회차는 조회되지 않고 조회로 데이터가 변경되지 않는다.

## 데이터·제외 범위

- 기존 테이블 재사용. [확정 DB 스키마](../database/SCHEMA.md). 전달본에는 seed를 포함하지 않는다.
- 기존 데모는 모집·설정 이력 각각 최신 100건을 제공한다.
- 고객 수령 처리, 재발주, 입고 추적은 이 단계에 포함하지 않는다.
- 원 프로젝트의 구현·검증 근거는 `docs/steps/STEP-4.md`에 있으며 이 전달본에는 포함하지 않았다. 이번 문서 작성으로 구현을 재검증한 것은 아니다.
