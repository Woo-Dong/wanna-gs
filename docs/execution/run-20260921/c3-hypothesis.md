# C3 — 비추론 모델의 구조화 응답 비교

C2는25/30 PASS였지만3개 응답이 출력3200 상한에 도달했고 기준선 정상4건 회귀가 있어 채택하지 않는다. 전체 입력 tokens는 줄었으나 P95 36.6초와 불완전 응답은 남았다. 실패를 삭제하거나 validation으로 통과를 찾지 않는다.

C3는 OpenAI API 단일 경로와 동일 카탈로그·참조 codec·schema를 유지하고 GPT-4.1-mini-2025-04-14를 별도 Preview branch에서 비교한다. 이 모델은 공식 문서상 비추론, Responses/Structured Outputs 지원 모델이다. 요청에서 reasoning 속성을 완전히 제외하고 출력3200·45초·재시도0·storefalse를 유지한다. 기존 GPT-5-mini의 설정과 가격 계산도 보존한다. 모델 변경은 계정 접근/한국어 품질이 확인됐다는 뜻이 아니며 실제 응답 모델을 검사한다.

동시에 기존 범위 요구 두 곳을 명확히 한다: 실제 카드결제/본부 실행을 상품 찾기로 임의 변환하지 않으며, 경영주 제안 버전이 같고 stale=false이면 버전 숫자 자체를 이유로 재확인을 요구하지 않는다. case ID·특정 상품·정답 하드코딩은 없다. 그러므로 이는 모델 하나의 단독 효과 실험이 아니라 제한된 복합 복구 후보다.

공식 근거(2026-09-21 직접 확인): [GPT-4.1 Mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini). uncached 입력100만당$0.40·출력$1.60으로 보수 추정하고 실제 공급자 청구·계정한도와 구분한다. unknown 모델/사용량은 null을 유지한다. 개발 선별 중 미래 필수960attempt 비용 계획은$10.08(회당$.0105)이며 최악비용 보장은 아니다. 전체2400회/$15를 늘리거나 유료 구매하지 않는다.

동일30dev를 먼저 측정한다. validation84, 두 번째 validation, 보호holdout 및 두 역할 UX는 기준 충족과 별도 실행 승인 후 진행한다. C1/C2 및 B0 실패를 그대로 보존하고 기존 UX 상대비교 NOT_READY를 면제하지 않는다.
