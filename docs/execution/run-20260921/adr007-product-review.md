## P007-01 — 전체 연구 STOP의 판정 우선순위 명시 필요

반례: best56개가 모두 정상인 상태에서 baseline 마지막 workload가 성공3개 후 auth/unknown/예산 오류로 전체 STOP했다. 이후 계획된 나머지를 NOT_RUN으로 모두 기록하면 ‘56개 trial이 기록됨’, workload별 baseline 정상≥3, best56/56은 형식상 모두 충족할 수 있다. 중단된 연구가 조건부 집계만으로 비교 PASS가 되어서는 안 된다.

최소 보완: **어느 arm에서든 전체 연구 STOP 조건이 한 번 발생하면 arm 순서·이미 확보한 정상 표본 수·나머지 NOT_RUN 기록 완료 여부와 관계없이 전체 비교 NOT_READY**라고 판정 절에 명시한다. 모든 planned trial의 기록은 분모 보존이지 실행 완료가 아니며 STOP을 해제하는 조건이 아니다. 이 보완은 새 기준 확장이 아니라 초안의 auth/usage/출처/예산 중단 목적을 판정까지 연결한다.

## 구현 이후 필요한 독립 검증 연결

채택 동의와 기구 구현 PASS는 다르다. 실제 구현 시 알려진 오류 trial이 FAIL로 남고 다음 사전 반복으로만 진행되는 정상 인접 흐름, unknown/auth/소스/예산 STOP, baseline 성공2개뿐인 workload, 성공3개+실패4개 분모, best55PASS/1FAIL, 중복/누락/임의 첫3선택, 옛48과 새112의 총160 출처를 검사해야 한다. 새 결과를 본 뒤 반복수·모델·기준선·상품을 바꾸지 않는다. 이 리뷰가 호출 승인이나 G5 예외가 되지 않는다.
