# D50 기능 릴리스의 알려진 한계

사용자 직접 결정 D50에 따라 추가 고품질 최적화를 종료했다. 이번 출시는 주요 기능 확인 범위이며, 원래 전체 품질 G5는 NOT_READY다.

- C11 보호 v3는84개 중75개 PASS,9개 FAIL이다. 고객 명확36/40·불확실17/20, 경영주 명확13/15·불확실9/9다. 원본/정답/기준/비용을 수정하거나 재평가하지 않았다.
- 일부 자연어에서 잘못된 상품 후보, 불필요한 질문, 미식별·모호함 처리 오류, 이전 대화 해석 오류와 경영주 되돌리기 제안 오류가 남아 있다. 사용자는 상품·점포·수량·가격·동의와 경영주 반영안을 확인해야 한다. 모델 제안은 사용자 승인이나 실제 거래 확정과 다르다.
- 새 UX 비교112회는 미실행 상태에서 사용자 지시로 종료했다. 과거48회(성공13·실패2·미실행33) 이력을 보존하며 사용성 비교 개선을 주장하지 않는다.
- 한 PC/한 탭의 브라우저 SQLite 시연이다. 데이터·GS 거래·결제는 모의이며 다중 사용자 서버 권한·실결제·실제 점포 주문을 제공하지 않는다.

고객·경영주 독립 실제 기능 QA와 최종 Production 확인은 별도 증거로 판단한다. 이 한계 문서 자체는 기능 PASS나 최종 배포 성공의 증거가 아니다.
