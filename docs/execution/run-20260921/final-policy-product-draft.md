## C2 변화와 아직 충족하지 못한 필수 항목

1. **자연어 품질은 현재 미충족/진행 중이다.** B0 공식336 중227PASS/109FAIL(응답 실패51 포함), C1 dev30은22PASS/8FAIL 및 기존 정상7회귀로 기각했다. C2는 현재 평가 중이다. columns/rows에8속성을 보존하고 안정적인 전역 pN 참조를 출력 schema→canonical SKU 복원→기존 verify로 연결한다. 자유 사용자 문장, 실제 동의, SQLite 권한은 변경하지 않는다. 정확한 이름 언급도 추가 조건을 충족했다는 증거로 취급하지 않는 prompt를 확인했다. [별도 기술 검토](n03-c2-technical-review.md)의21+9검사는 모델0 기술 증거이며 실제 정답·업무 성공을 대체하지 못한다. 출력3200은 재시도0/45초/goal2400회·$15 한도 확대가 아니다.
2. **UX 상대 비교는 NOT_READY다.** ADR003 고정8×3 및 ADR006의 지정 recovery가 모두 완료되지 않았다. 최초24는2PASS/1FAIL/21미실행, recovery24는11PASS/1FAIL/12미실행, 누적48은13PASS/2FAIL/33미실행이다. 실패·미실행 분모와 각각의 source/run을 모두 보존한다. 현재 계약에서 세 번째 B0 실행, C2로 B0 대체, fixture 대체, 성공 사례만 선택한 비교, 기준 완화를 허용하지 않는다. [기존 계약 검토](ux-baseline-comparison-contract-review.md)대로 정상 best 절대 성공·일부 편의성 자료를 추가해도 전체 비교 및 G5 완료와 분리한다.
3. **최종 best·validation2·보호 holdout84·G5·G6는 미실행이다.** 현재 후보 Preview/CI 통과는 품질 채택이나 제출 완료가 아니다. 최종 두 역할 actual model/browser/SQLite 및 최종 source/deployment 결속, 심사자 접근 가능한 제출 URL, Production 검증은 아직 필요하다. I01 소스와 동일한 UI/domain의 좁은 증거는 유지하되 C2 모델 경로까지 이전 live E2E로 인증하지 않는다.
4. **현재 인덱스와 컨텍스트는 인계 전에 정합성 정리가 필요하다.** DECISION_INDEX 서두의 ‘앱 구현 아직 시작하지 않았다’, ADR002/003 실행 미검증 요약, ADR006 재측정 미실행은 이후 증거와 어긋난 과거 상태다. ADR의 정책 자체를 바꾸지 않고 현재 실행 결과 링크·상태 및 manifest ACK를 소유자가 갱신해야 한다. 이번 보고서는 공통 문서를 직접 수정하지 않았다.

R28~34·39~44의 인증/실행기·실험 분모·독립 검토·예산·출시 인계는 기존 preflight/I01/기구 검토와 현재 미완료 항목으로 나눈다. 공개 B0 집계와 checker unit 성공이 actual G5 manifest를 대신하지 않으며, 최종 감사 두 관점 중 이 초안 한 건으로 완료 처리하지 않는다.

## 범위 밖·비차단 후속

본부 실행 화면, 사진/링크/레시피 입력, 실제 결제, 외부 DB/pgvector, 다중 사용자 경합·실제 로그인, D40 미채택 팀원 제안은 추가하지 않는다. 상품 조사 분류의 인접 카테고리·제조사 편중은 이미 기록된 한계이며, 이를 이유로 평가 정답이나 제외 집합을 넓혀 성공 처리하지 않는다. 경영주 일부 raw 상태코드의 한국어 카피 개선은 기존 비차단 후속으로 남기고 핵심 상태/다음 행동 누락과 혼동하지 않는다.
