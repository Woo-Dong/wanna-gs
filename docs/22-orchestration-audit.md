# 에이전트 운영 방식의 감사와 개선

최초 구현 기준. 제품 정책뿐 아니라 역할·맥락·계획·검증·협업 방식의 빈틈도 검사한다. 감사 결과로 작업 지연·책임 누락·검증 공백을 줄인다.

## 단일 운영 감사자

조정자와 다른 method-auditor를 배정한다. [운영 감사 스킬](../.agents/skills/wanna-gs-orchestration-audit/SKILL.md)을 적용한다. 작업은 읽기/관측/개선 제안 중심이며 자기 제안을 스스로 승인·검증하지 않는다.

관리 계층은 coordinator → 작업자/검증자/운영 감사자 한 단계로 제한한다. 운영 감사자는 또 다른 manager/auditor를 생성하지 않는다. 개발자는 유용한 독립 하위 작업이 필요하면 조정자에게 요청해 기존 DAG에 편입한다. 이 규칙은 도구 권한을 늘리는 것이 아니다.

## 언제 검사하는가

- PLAN-READY 전: 역할·데이터·정책·테스트·의존성·종료 기준 공백.
- 첫 G3/G4 통합 후: 실제 업무 인계와 공유 맥락이 작동하는지.
- 같은 종류 실패/재작업 반복, 계약 변경 전파 누락, 장시간 증거 없는 진행, 모델 부적합, 실험 정체 발생 시.
- G5 직전: 완료 주장·폐기 결정 재도입·CI/정책/QA 증거 일치.

매 도구 호출마다 감사를 만들지 않는다. 동일 이슈는 초안+보완 두 검토 안에 `현행 유지 / 제한 시험 / 변경 채택 / 기각·기록`으로 처분한다. 새로운 실제 반례가 있으면 다시 열 수 있으나 단순 의견 반복은 후속 과제다.

## 검사 목록

| 축 | 증거로 확인할 것 |
|---|---|
| 요구 | 사용자 핵심 정의가 task/ADR/코드/테스트로 연결되는가 |
| 맥락 | manifest/hash·현재 정책 버전·변경 ACK가 일치하는가 |
| 역할 | 같은 파일 다중 작성, 자기 검증, 책임 공백/병목이 있는가 |
| 의존성 | 존재하지 않는 검사 선행조건, CI/배포 순환, 무한 대기가 있는가 |
| 모델 | 위험도 대비 모델/추론 선택·승격 근거가 있는가 |
| 검사 | 0개/skip/fixture/stale를 PASS로 오기록했는가 |
| 재발 | 폐기 정책·실패한 접근을 새 이름으로 되풀이하는가 |
| 실험 | holdout 누수·후보 자기승인·무의미한 반복·중단 기준 변경이 있는가 |
| 종료 | 필수 미완료를 포기 처리하거나 범위 밖 개선을 무한 늘리는가 |

## 방법 변경의 작은 실험

[운영 실험 양식](templates/method-experiment.md)에 trigger·실제 실패/재작업·기준선·가설·최소 변경·관찰 구간·성공 조건·부작용·복구를 기록한다. 예를 들어 공유 계약 수정이 누락되는 현상이 있으면 manifest ACK를 추가한 다음 한 통합 단계에서 누락 여부를 비교한다. 단순히 더 많은 에이전트를 띄우는 것을 개선으로 보지 않는다.

조정자는 위임 운영 ADR에 제안자 외 독립 검토를 붙여 제한된 시험을 승인한다. 시험은 작업 소유권이나 명시적 권한 경계를 넘지 않는다. 성공 척도는 시작 전 정하고, 품질/재발/정합성이 좋아지지 않거나 부작용이 크면 현행으로 복구한다. 결과가 불명확하면 채택이 아니라 미검증으로 남긴다.

사용자 불변식·필수 QA·보호 규칙·실험 중단 한도를 완화해 속도를 높이는 안은 개선안이 아니다. 런타임 모델이 운영 문서를 직접 덮어쓰게 하지 않는다. 승인된 문서/CI 변경은 정상 PR·검증 경로로 반영한다.

## 끝내는 조건

발견한 중대한 공백을 수정·검증하고 범위 밖 제안을 이유와 함께 후속 과제로 기록하면 감사를 마친다. 제품 goal 완료에는 중대한 운영 모순 미해결 0건과 유효한 제품 게이트가 모두 필요하다.

## 목적에서 벗어난 수정 검사

감사자는 [card.md](../card.md)의 목적 보존 기록을 표본 확인한다. 오류 수정 뒤 정상 흐름이 사라지거나 필수 기능을 향후 작업으로 미룬 사례, 인계 과정에서 CORE/유효 ADR이 빠진 사례를 조사한다. 같은 문제가 반복되면 담당 역할·작업 계약·복구/검증 절차의 원인을 고치고 영향 범위만 재검증한다. 카드 문구를 더 쌓는 것만으로 해결했다고 판정하지 않는다.
