# 검토 목록: 모호한 정책·숨은 가정·검증 조건

기준일: 2026-09-20 · 상태: 자율 정책·검증 점검표. 기존 O-01~O-12를 구체화하고 추가 R-01~R-44를 정리했다. 총 56개 검토 항목이며 앞으로 발견되는 사항은 계속 추가한다. 이 목록의 권장안은 사용자 확정 결정이 아니다.

## 읽는 법

- P0: 해당 기능의 계약/구현 전에 해결. 모든 P0 때문에 독립 작업을 중단하지 않는다.
- P1: 해당 통합·최종 시연 전에 해결. 품질 기준과 평가 정답은 해당 테스트를 만들기 전에 정한다.
- 선택: 핵심 완료를 막지 않는 후순위.
- A: 위임 제품 정책. 17번의 초안·두 독립 검토·ADR 채택·검증으로 해결하며 사람 답변을 기다리지 않는다.
- E: 개발 에이전트가 명세와 근거를 갖고 결정할 구현 사항. 사용자에게 라이브러리·잠금 방법 선택까지 떠넘기지 않는다.
- X: 주최 측/계정/배포 환경에서 실제 확인할 조건. 문서 가정으로 통과 처리하지 않는다.

개별 항목은 실행 시 채택/검증할 상태다. 사용자에게 답을 요구하는 질문지가 아니다. 완료 시 각 행의 근거를 결정 기록 또는 작업·게이트 보고서에 연결한다. 현재 제품 결정의 원장은 [02번](02-decisions-and-open-questions.md), 추가 공백의 전체 검토 목록은 이 문서다.

## R-31~R-33 추가 해석

OpenAI 모델 접근·사용량 한도는 실제 계정에서 확인한다. split별 실행·반복·후보·재시도·holdout/G6 여유를 사전 계산한다. 429 속도 제한은 제한 재시도, quota 소진은 호출 중단·외부 차단으로 기록한다. 제공자/fixture 자동 전환은 하지 않는다. 합격선은 유지한다. 자세한 구현 준비는 18번, 품질 기준은 21/23번을 따른다.
